# ShopPilot – Modern Sneaker E-commerce Frontend

ShopPilot is a modern, responsive sneaker e-commerce web application built with Next.js, React, TypeScript, and Tailwind CSS. It provides a smooth online shopping experience with an intuitive interface for browsing products, exploring categories, managing shopping carts, saving favorite items, and placing orders.

The application includes a customer-facing storefront and an admin dashboard for managing products and orders. It currently uses browser localStorage to demonstrate data persistence and frontend functionality, with a separate Express.js backend planned for future integration.

### Key Features

- **Modern Homepage:** Attractive hero section, featured products, product categories, promotional sections, and testimonials.
- **Product Catalog:** Browse sneakers with search, category filtering, price filtering, and sorting options.
- **Product Details:** View product information, images, prices, ratings, and select shoe sizes and quantities.
- **Shopping Cart:** Add products, update quantities, remove items, and calculate subtotal, shipping, and total prices.
- **Wishlist:** Save favorite products and manage a personal wishlist.
- **Checkout:** Customer information form, delivery address, and multiple demo payment options.
- **Order Management:** Place demo orders, view order history, and track order status.
- **Admin Dashboard:** View sales statistics, recent orders, and manage store products and orders.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.

### Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- Browser localStorage

### Project Status

Frontend development is currently in progress. The existing shopping and admin workflows use localStorage for demonstration purposes. Backend integration with Express.js, PostgreSQL, and Prisma is planned for the next development phase.
